# 内置、URP、HDRP 适配

模板现在按**实际启用的渲染管线**准备材质、相机和模板灯光。Core、设计模式、实体/FSM、玩法、输入、背包、叙事、音频、UI、动画和存档使用同一份业务代码。

本次验证版本为 **Unity 2022.3.62f3c1、URP 14.0.12、HDRP 14.0.12、Direct3D 11**。可选适配程序集的版本范围为 SRP 14.x；其他 Unity/SRP 主版本尚未验证。

## 在编辑器切换

退出 Play，等待脚本编译完成，然后使用以下菜单：

| 菜单 | 效果 |
| --- | --- |
| `Guisha > Rendering > Use Built-in` | 使用内置管线 |
| `Guisha > Rendering > Use URP` | 缺少包时安装 URP 14.0.12，创建/复用管线和 Renderer 资产 |
| `Guisha > Rendering > Use HDRP` | 缺少包时安装 HDRP 14.0.12，创建/复用管线资产并初始化 HDRP 全局设置 |
| `Guisha > Rendering > Refresh Shader References` | 刷新构建需要保留的 Shader 引用 |
| `Guisha > Rendering > Validate Current Pipeline` | 输出当前有效管线并检查适配器是否存在 |

URP/HDRP 菜单会启用 Linear 色彩空间，资产保存在 `Assets/GuishaDemo/Rendering`。切换菜单修改 Graphics 的默认管线，并清空**当前质量等级**的管线覆盖；其他质量等级已有的独立覆盖会保留。`Project Settings > Quality` 的非空管线覆盖优先于 Graphics 默认值。

打开工程不会自动安装两个 SRP 包。没有安装 URP/HDRP 时，相关可选程序集不参与编译，内置管线可独立使用；两个包同时安装也不会改变管线判断。开发时选择项目的管线后再构建 Player；本次验证不包含在一个正式 Player 内同时热切换三套后端。

## 已接入的功能

| 功能 | 适配方式 |
| --- | --- |
| 灰盒地图、玩家/NPC/交互物 | 根据活动管线创建 Lit 材质 |
| Addressables 生成的实体 | `EntitySpawned` 事件触发层级准备 |
| 附加场景与副本切换 | 加载完成后准备场景对象，模板曝光随内容根启停 |
| 受击对象池特效 | 借出时准备标准材质，再启用特效对象 |
| 玩家镜头和过场镜头 | 为 URP/HDRP 补齐附加相机数据，保留美术相机原有参数 |
| 模板方向光 | 内置/URP 使用普通强度，HDRP 显式使用 Lux |
| HDRP 曝光 | 模板使用自己持有的固定曝光 Volume，卸载时配对销毁 |
| 材质生命周期 | 使用副本转换，保留共享源资产；重复刷新和对象池启停不重复创建 |
| 构建入口 | 构建前刷新 Resources 中的 Shader 引用并检查活动适配器 |

模板的方向光强度、HDRP 曝光和背景色在 `Assets/Resources/Guisha/RenderingSettings.asset` 调整。`PipelineSceneSetup` 只管理显式指定的模板相机和方向光。外部场景更高优先级的 Volume 仍可能改变最终外观。

## 调用与继承

启动器会创建继承 `MonoSingleton<RenderingManager>` 的第七个全局管理器，无需手动挂载。自定义运行时生成代码可调用：

```csharp
using Guisha.Rendering;
using UnityEngine;

// 给自己生成的角色、拾取物或特效准备材质和相机。
RenderPipelineService.PrepareHierarchy(spawnedObject);

// 创建当前管线的独立材质；创建者负责在不再使用时 Destroy。
Material owned = RenderPipelineService.CreateMaterial(Color.red);
Material unlit = RenderPipelineService.CreateMaterial(Color.white, unlit: true);
```

上面是方法体内的调用片段，`spawnedObject` 表示调用方已经创建的 GameObject。

| 类型/API | 作用与拥有权 |
| --- | --- |
| `RenderPipelineService.Current` / `Classify(asset)` | 识别当前有效资产或指定资产；未知 SRP 返回 `Unsupported` |
| `Settings` / `RenderingSettings.GetShader(kind, unlit)` | 读取配置或取得显式 Shader 引用 |
| `RequireAdapter()` / `Register(adapter)` | 取得或注册 `IRenderPipelineAdapter`；缺失实现时明确报错 |
| `ShaderName(kind, unlit)` / `IsTemplateShader(name, out unlit)` | 查询标准 Shader 映射与可迁移范围 |
| `CreateMaterial(color, unlit)` | 创建调用方拥有的材质 |
| `AdaptMaterial(source)` | 需要转换时返回调用方拥有的新副本；无需转换时返回源引用 |
| `SetColor(material, color)` | 使用目标 Shader 的颜色属性写入颜色 |
| `PrepareHierarchy(root)` | 包含未启用子对象，补齐材质绑定和相机数据 |
| `PipelineMaterialBinding.Refresh()` | 从原始共享材质重建必要副本；组件负责释放副本 |
| `PipelineSceneSetup.Apply()` | 重新配置绑定的模板相机、方向光与环境 |
| `HighDefinitionEnvironment.Initialize(EV)` | HDRP 可选组件创建并持有曝光 Profile |
| `RenderPipelineChanged(previous, current)` | 管线变化事件；由 RenderingManager 广播 |
| `RenderingSetup.Activate(kind)` | Editor API；包安装完成后配置目标管线 |
| `RenderingSetup.BuiltIn/Universal/HighDefinition()` | 对应三个切换菜单；后两者包含异步包安装 |
| `RenderingSetup.RefreshShaderReferences/ValidateCurrent()` | 刷新资源引用、检查当前适配器 |

扩展自定义渲染管线时，实现 `IRenderPipelineAdapter` 的 `Kind`、`PrepareCamera`、`ConfigureSun`、`ReleaseSun`、`CreateEnvironment`、`ValidateMaterial`，并注册实现。还需扩展 `RenderPipelineKind`、`Classify` 和 Shader 映射。可参考 `UniversalPipelineAdapter` 与 `HighDefinitionPipelineAdapter` 的条件程序集；业务层不应直接引用 SRP 包类型。

## 材质边界

自动迁移范围是内置 `Standard`、`Unlit/Color`、`Unlit/Texture`、模板内置 Unlit、URP Lit/Unlit、HDRP Lit/Unlit。保留基础颜色、主纹理、UV 平铺与偏移、金属度、平滑度及基本透明/裁剪状态。目标材质的配置由各管线适配器完成。

**第三方 Shader、自定义 Shader Graph、专用粒子 Shader、Renderer Feature/Custom Pass，以及不同通道布局的 PBR/Mask 贴图，需要提供对应管线的版本。** 框架保留未识别的 Shader，不执行有损猜测转换。贴图通道重排、法线/自发光等高级材质迁移未包含在此通用转换器中。uGUI 的标准 UI Shader 保留原实现。

如果生成代码在 `PrepareHierarchy` 之后再次替换源材质，需移除并重新创建绑定组件，或在最终材质赋值完成后才第一次调用准备入口。

可选的低 San 后处理管理器尚未实现；此项适配没有宣称新增整套后处理效果。HDRP 固定曝光用于现有模板场景的可见照明。

## 验证记录（2026-10-21）

三条管线分别通过 **52 项 EditMode + 5 项 PlayMode**。运行测试覆盖原有场景/存读档/副本/模式/动画流程，以及标准材质选择、源材质保护、UV 保留、材质复用与释放、动态实体生成和主相机离屏像素检查。

测试使用 NVIDIA GeForce GT 1030，截图尺寸 320×200；三条管线均产生可见画面，错误粉色像素为 0。最后还在 URP、HDRP 同时安装的工程中切回内置管线复测。截图仅展示主相机输出，屏幕空间 HUD 另外检查组件初始化。
