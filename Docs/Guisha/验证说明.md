# 当前验证结果（2026-10-21）

在 `E:\unity\Template` 的隔离副本中，使用真实 Unity 2022.3.62f3c1、Direct3D 11 分别验证内置管线、URP 14.0.12、HDRP 14.0.12。三条管线各通过 **52 项 EditMode + 5 项 PlayMode**，无失败或跳过。

EditMode 包含 Core、23 种设计模式、实体/FSM/玩法/动画回归，以及管线检测、Quality 覆盖优先级、材质颜色/贴图/UV 保留。PlayMode 包含灰盒与存档恢复、副本切换、玩法与动画、Addressables 实体生成、材质副本复用与销毁，以及真实 GPU 主相机像素检查。

三条管线均产生可见画面，错误粉色像素为 0。测试显卡为 NVIDIA GeForce GT 1030；还验证了 URP/HDRP 两个包同时安装后切回内置管线。原项目 ProjectSettings 与 Packages 未因本次验证改动。

结果 XML 与主相机截图见 [Validation/Rendering](Validation/Rendering)，配置、调用入口与材质边界见 [渲染管线适配](渲染管线适配.md)。截图不包含 Screen Space Overlay HUD，运行测试另检查了 HUD 初始化。

未执行正式 Addressables 内容构建或 Player 构建，未验收所有平台、GPU、第三方 Shader 与美术素材，也未进行真实音频素材的人工试听。最初使用 API 桩的 12 项检查和后续 44/3 项记录属于历史阶段，当前结论以本页列出的 Unity 实测为准。

## Unity 内验收

1. 安装依赖并导入，确认 Console 无编译错误，运行 EditMode 测试。
2. 生成灰盒，Play，检查移动、跑步耗体力、停止后恢复、蹲伏以及头顶有障碍时不能站起。
3. 转动镜头靠近墙面，确认相机不穿墙；隔着墙不能交互；准星命中后才显示提示。
4. 拾取鬼器、打开背包并使用，验证事件更新快捷栏和 San。
5. 阅读纸条、启动机关、开关门，绿色方块保存。消耗鬼器后 F9，应恢复背包、San、生命、位置、纸条/机关/解锁/拾取标记。
6. 和 NPC 对话，测试空格继续、数字分支；暂停/继续、背包开关、读取存档后确认输入锁释放。
7. 进入两个副本再返回主场景，确认只有一个玩家、相机、EventSystem、AudioListener 在工作，UI 面板正确注册；切换期间不允许重复切换。
8. 鬼怪在烘焙或运行时生成的 NavMesh 上测试：视觉被墙遮挡、跑步声调查、追击、近距离攻击、丢失后返回。死亡后 F9 恢复。
9. 给 PlaySoundRequested/BgmRequested 指定真实音频，验证池归还、距离衰减、遮挡层和淡入淡出。
10. 在 Addressables Profiler 中观察加载/释放，检查正常销毁、场景卸载、失败地址和取消路径。构建 Addressables 内容后再构建桌面 Player。

需要在实际项目检验的边界：自定义模型与碰撞、中文字体、动态门导航、第三方材质与平台渲染、Timeline 相机、平台存储、关闭 Domain Reload 后重复进入 Play Mode，以及 Addressables 版本差异。它们不由本地 API 桩编译证明。
